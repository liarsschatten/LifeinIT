# RBAC 
Role-Based Access Control
Berechtigungen werden nicht direkt an Personen vergeben, sondern an feste Rollen (z. B. „Buchhalter“, „Admin“, „Gast“). Personen erhalten die Rolle und damit automatisch die verknüpften Rechte.
# DAC
Discretionary Access Control
Der Besitzer einer Datei oder Ressource entscheidet selbst (diskretionär), wer darauf zugreifen darf und welche Rechte (lesen, schreiben) diese Person erhält.
# MAC 
Mandatory Access Control
Eine zentrale Instanz oder das Betriebssystem legt starre Sicherheitsrichtlinien und Klassifizierungen (Sicherheitsetiketten) fest. Anwendende können diese Rechte nicht eigenmächtig ändern.
# ABAC
Attribute-Based Access Control
Zugriffe werden dynamisch über Attribute bewertet. Dazu gehören Eigenschaften des Benutzers (Abteilung, Sicherheitsfreigabe), der Ressource (Vertraulichkeitsstufe), der Umwelt (Uhrzeit, Standort) oder des Geräts.
